# Control Panel

Панель управления локальными Vite-сервисами. Запустите `npm install` в корне (npm workspaces установит зависимости и для сервисов), затем `npm run dev` в корне.

В development-режиме API панели запускает и останавливает сервисы через кнопки интерфейса. Порты сервисов: 5174 и 5175.

У каждого сервиса есть `npm run lint`, `npm run format` и `npm run format:check`. Результат `lint` также доступен по кнопке «Проверить код» в панели.

Настройка сервисов находится в `config/services.json`. Там можно изменить название, иконку, порт, путь к проекту и аргументы команд кнопок. Для остановки сейчас используется встроенная команда `process:terminate`, которая завершает процесс, запущенный кнопкой «Запустить».
